# Codex Orchestrator v0.5.0

Persistent coding chat with follow-up prompts and an orchestration switch in the same session.

```sh
npm install -g https://github.com/chittranshsharma/Codex-Orchestrator/releases/download/v0.5.0/codex-workflow-0.5.0.tgz
cd /path/to/your/git-repository
cwf
```

- Chat normally with orchestration OFF, then use `/orchestrate on` for coordinated jobs and `/orchestrate off` to return to direct work.
- The persistent lead reuses its Codex thread across prompts, mode changes and resumed chats. Workflow outcomes and patch status are passed into follow-ups.
- Use `/agents manual` or `/agents auto` for workers, `/model MODEL [EFFORT]` for the lead, and `/jev on|off` for Auto workflows.
- `/runs`, `/history`, `/status` and `/apply RUN_ID JOB_ID` keep workflow results accessible inside the chat.
- `/exit` saves; `cwf chats` lists sessions; `cwf chat CHAT_ID` resumes from the same repository.
- The one-task `cwf start` and existing run/plan/apply commands remain available.

OFF mode can edit the current checkout; ON mode prepares patches in isolated worktrees with independent verification before explicit application. Generated workflow scripts require review and RUN confirmation. This is a custom Codex SDK client, not a complete replacement for every native Codex CLI feature. TypeSafe credentials are required for live Jev requests; live Jev inference and savings remain unverified.

Requires Node.js 22+, Git, and working Codex authentication. The release is gated on automated tests on Windows, Ubuntu, and macOS. Compiled JavaScript is included; npm installs runtime dependencies. SHA256SUMS.txt records the package checksum.
