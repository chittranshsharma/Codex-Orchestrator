# Codex Orchestrator v0.5.1

The persistent chat now uses the terminal control room design from the workflow dashboard. A live view appears while the lead works, showing the current mode, model, request, elapsed time, and activity. Workflow jobs still use the existing agent dashboard.

The `/model` command accepts both `/model MODEL EFFORT` and `/model MODEL/EFFORT`. API errors are shown as readable messages, and long error and resume text wraps instead of being cut off.

Install globally:

```sh
npm install -g https://github.com/chittranshsharma/Codex-Orchestrator/releases/download/v0.5.1/codex-workflow-0.5.1.tgz
```

Run `cwf` from any Git repository. Existing chats can be resumed with `cwf chat CHAT_ID` from their original repository.
