# Codex Orchestrator v0.4.0

A public CLI release with real Codex execution, a guided task launcher, explicit Manual/Auto assignment, isolated edits, independent patch verification, saved runs, and optional TypeSafe Jev decisions.

## Install

Requires Node.js 22+, Git, and a Codex login with access to the configured models.

```sh
npm install -g https://github.com/chittranshsharma/Codex-Orchestrator/releases/download/v0.4.0/codex-workflow-0.4.0.tgz
```

The package includes compiled JavaScript. npm installs the runtime dependencies. No source build is required for this package.

## Run a real task

```sh
cd /path/to/your/git-repository
cwf
```

Enter the task, choose Manual or Auto, review the generated workflow, and type RUN to launch it. Manual asks you to select a model and effort for every job, including the planning job. You can also begin with `cwf start "Find and fix the session expiry bug"`.

Keep using `codex` for ordinary chat/tasks whenever you want. The orchestrator is a separate opt-in command. `cwf demo` is only an optional simulation to preview the UI.

Prepared changes remain in separate worktrees. Read the report and explicitly apply a verified patch with `cwf apply RUN_ID --task EDIT_JOB_ID`.

## Validation and limits

Automated tests cover runtime behavior, manual approvals, Jev contracts/failures, CLI validation, terminal layout, and approval before executing generated workflows. The release workflow gates publishing on Windows, Linux, and macOS test jobs.

Real Codex smoke and audit pilots have been run on Windows. Live Jev inference and routing savings have not been verified because no TypeSafe key was available. Coordinator scripts are trusted local JavaScript, not securely sandboxed. A public release does not imply benchmarked savings or universal compatibility with every repository/tool.

SHA256SUMS.txt records the package checksum. Source code and full usage documentation are available in the repository.
